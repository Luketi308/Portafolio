# Portfolio Personal — Lucas Lafuente

Portfolio web personal desarrollado para presentar mi perfil como estudiante de Programación, mostrar algunos de mis proyectos, compartir mis conocimientos y ofrecer distintas formas de contacto.

## Vista general

El sitio está organizado en secciones para facilitar la navegación:

- **Inicio:** presentación y accesos directos a los proyectos y al contacto.
- **Sobre mí:** breve descripción personal, ubicación y formación.
- **Proyectos:** selección de trabajos realizados, con una descripción y enlaces a sus respectivos sitios o repositorios.
- **Habilidades:** tecnologías y áreas de programación que forman parte de mis conocimientos.
- **Experiencia y formación:** recorrido académico y formación actual.
- **Contacto:** correo electrónico y enlaces a GitHub y LinkedIn.

## Tecnologías utilizadas

- **HTML5:** estructura y contenido de la página.
- **CSS3:** diseño visual, distribución de elementos, efectos y adaptación a distintos tamaños de pantalla.

El proyecto utiliza HTML y CSS, sin necesidad de instalar dependencias ni configurar un entorno de desarrollo.

## Cómo ejecutar el proyecto

No requiere instalación. Para visualizarlo localmente:

1. Descargá o cloná este repositorio.
2. Abrí la carpeta del proyecto.
3. Ejecutá `index.html` con un navegador web.

También podés utilizar la extensión **Live Server** de Visual Studio Code para visualizar los cambios mientras editás los archivos.

## Personalización

- Modificá los textos y enlaces desde `index.html`.
- Cambiá colores, tipografías, espaciados y distribución desde `style.css`.
- Reemplazá o agregá imágenes dentro de la carpeta `img/` y actualizá sus rutas en el HTML.
